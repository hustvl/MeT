Memory Transformer

Native Scalable Memory Models with Transformers

Making native visual memory an independently scalable architectural resource, establishing two scaling trends with compact states and low computational overhead

  • Ziyang Xu1
  • Lucia Cascone2
  • Aniello Castiglione2
  • Michele Nappi2
  • Wenyu Liu1
  • Xinggang Wang1✉

1 Huazhong University of Science and Technology2 University of Salerno

✉: Corresponding Author

Abstract

We introduce Memory Transformer (MeT), a novel method for native visual memory modeling that opens a new scaling dimension for vision Transformers. Its hierarchical memory maintains recurrent states updated from spatial features and returned through residual readouts, making persistent context an intrinsic part of the representation hierarchy. A separate hidden-state width controls memory capacity independently of backbone width and depth, while the retained state remains bounded as the input sequence grows. MeT reveals two complementary scaling trends: increasing memory capacity consistently improves accuracy at a fixed spatial backbone, and larger models deliver further gains at matched memory widths. Studies spanning three model sizes and fifteen capacity configurations demonstrate these gains with compact states and low computational overhead relative to same-size ViTs; per-frame latency remains nearly unchanged during memory scaling. On THUMOS14 and SSv2, MeT-Large outperforms state-of-the-art methods in accuracy, improving mAP and Top-1 accuracy over same-size ViTs by 6.69 and 26.91, respectively, with comparable parameter counts, GFLOPs, and GPU peak. Compared with TRecViT-Large, MeT-Large uses 92.7% less persistent state and provides approximately 3.0× faster causal framewise inference. MeT establishes native visual memory as an independently scalable architectural resource, opening a direct route to stronger visual models.

    Architecture

    Persistent state at multiple feature depths

    MeT interleaves ViT blocks with recurrent memory stages. A pre-normalized GRU updates token states, and residual readouts bring their history into the current features. Intermediate stages carry patch and CLS history into subsequent spatial blocks, while the final stage refines the CLS representation for prediction. The recurrent width H controls how much state each token carries.

    Experiments

    Memory scaling raises accuracy at nearly constant latency

    Across fifteen configurations, wider recurrent states improve accuracy at each backbone size. Increasing memory width changes measured THUMOS14 latency by at most 0.03 ms per frame within each size. MeT-Small exceeds ViT-Large on both benchmarks with less than one-tenth of its parameters and per-frame FLOPs.
